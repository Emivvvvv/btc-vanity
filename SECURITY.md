# Security Policy

## Supported versions

Security fixes are provided for the latest published release.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository when
available. If it is unavailable, open an issue asking for a private reporting
channel without including exploit details, generated private keys, seed
material, or other secrets.

Include the affected version, platform, enabled Cargo features, impact, and the
smallest safe reproduction. Please allow time to investigate before publishing
details.

## Wallet safety

Never submit a real generated private key in a report. Reproduce wallet issues
with disposable keys that have never held funds. See the
[security guide](docs/src/security.md) for operational guidance.
